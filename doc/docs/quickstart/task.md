# 查看任务
点击 `任务管理` 导航，进入任务页面，可以看到上一节发布的应用执行历史记录：

![](/images/task.jpg)

点击刷新按钮（本页面不会自动刷新），直到任务执行结束。

可点击任务最左边的 `>` 按钮展开任务，看到任务的执行详情（任务未执行完成也可以展开）：

![](/images/task-expand.jpg)

展开页面列出了本次任务涉及到的所有工作负载，其所在的集群、命名空间、负载名称、容器名称、发布时使用的镜像、最新的 Pod 状态，以及输出信息（如有，通常是报错信息）。

至此，使用 Lizardcd 进行一次完整的应用部署流程就结束了，更多的使用介绍，请您继续关注下述章节。
